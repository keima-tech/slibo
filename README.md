# Slibo

Slibo はブラウザ上で動作するスライド作成アプリです。読み込んだ HTML ファイルは以下の外部ライブラリを CDN 経由で使用しています。

- **Vue 3**（`unpkg.com/vue@3`）— UI の状態管理とレンダリング
- **Tailwind CSS**（`cdn.tailwindcss.com`）— スタイル
- **lucide**（`unpkg.com/lucide`）— アイコン
- **PptxGenJS 3.12.0**（`cdn.jsdelivr.net/gh/gitbrent/pptxgenjs`）— PowerPoint (.pptx) 出力
- **Google Fonts** — Noto Sans JP / BIZ UD Gothic

対応言語は **日本語（既定）と English** の 2 言語（設定画面で切替可）。

---

## 1. 画面の構成

アプリは主に 4 つの領域に分かれています。

| 領域 | 役割 |
|------|------|
| 上部ツールバー | 全体操作（元に戻す、デッキ切替、フォント・テーマ、AI、設定、出力など） |
| 左サイドバー（スライド一覧） | 全スライドの表示、選択、並べ替え、複製、削除、テンプレート挿入 |
| 中央編集パネル | 選択中スライドの中身（テキスト／本文／データ）を編集 |
| 右プレビュー | 16:9 のリアルタイムプレビュー（自動拡縮）。画像のドラッグ移動・リサイズもここで行う |

編集パネルとプレビューの境界にある **スプリッター（仕切りバー）** をドラッグすると、両者の幅を調整できます。配置方向は「左右」（横並び）と「上下」（縦並び）を切り替えられます。

---

## 2. ツールバーの機能

### 元に戻す / やり直し
- **Undo（元に戻す）** ボタンと **Redo（やり直し）** ボタン。
- 入力途中の操作は 300ms 待ってから履歴に記録されます。
- 最大履歴数は設定画面で「10〜30」の範囲で変更可能（既定 20）。

### デッキ切替
- **サンプルデッキ**：12 枚構成のサンプル（表紙→アジェンダ→セクション→統計→2カラム→比較→ナンバリング→棒グラフ→表→プロセス→中央テキスト→クロージング）を読み込みます。
- **新規デッキ**：空のデッキに切り替えます（既定レイアウト 1 枚のみ）。
- いずれも現在のデッキを破棄するか確認ダイアログが出ます。

### フォント選択
- **Noto Sans JP**（既定）/ **BIZ UDゴシック** / **游ゴシック** から全スライド共通のフォントを選択。プレビューと出力に反映されます。

### カラーテーマ（スライドの配色）
- **コーポレート**（紺 `#002d5e` / ティール `#00b0ad`、既定）
- **プレミアム**（ダーク `#1a1a2e` / レッド `#e94560`）
- **ナチュラル**（グリーン `#2d5016` / ライム `#8bc34a`）
- 選択すると全スライドのメイン色とアクセント色が一括で変わります。

### AIでつくる
ボタンを押すと「AIでつくる」モーダルが開きます。詳しくは後述「8. AIでつくる」。

### 使い方ガイド
ヘッダー右側の「？（使い方ガイド）」ボタンで、はじめての訪問時に表示される**ウェルカム画面**と**チュートリアルツアー**を再表示できます。ツアーは各 UI 要素をスポットライトで照らしながら説明します。

### 配置方向
編集パネルとプレビューの並びを「左右」⇔「上下」に切り替えます（設定画面でも切替可）。

### 設定
歯車ボタンで「設定」モーダルを開きます。詳しくは後述「9. 設定」。

### 出力（エクスポート）
「出力」ボタンのドロップダウンから選択します。詳しくは後述「10. 出力」。

## 3. スライド一覧（左サイドバー）

### 新しいスライドを追加
サイドバー最下部の **「新しいスライドを追加」** ボタンで、デッキの末尾に新しいスライドを追加します（設定で選んだ「デフォルトレイアウト」で作成されます）。

### スライドの選択・並べ替え
- 一覧のスライドをクリックすると編集対象になります（選択中のスライドは強調表示）。
- **ドラッグ＆ドロップ**で順番を入れ替えられます。
- スライドにマウスを載せると表示されるボタンで「上へ」「下へ」移動も可能。
- 各スライドにはレイアウト名（例：カバー / 2カラム）がタグ表示され、下に見出しテキストのプレビューが表示されます。

### 複製 / 削除
- **複製**（コピーアイコン）：選択スライドの直後に同一内容のコピーを挿入します。
- **削除**（ゴミ箱アイコン）：スライドを削除します。最後の 1 枚は削除できません。

### テンプレート
サイドバー上部の「テンプレート」を開くと、以下の 8 種類のテンプレートが一覧表示されます。クリックすると**現在のスライドの直後**に挿入されます。

- 導入（cover）
- 比較（two-column）
- セクション（section）
- 表（table）
- ナンバリング（numbered-list）
- 中央テキスト（centered）
- クロージング（closing）
- アジェンダ（agenda）

### 全体プレビュー
サイドバー上部の「全体プレビュー」ボタンで、全スライドのサムネイルを一覧表示するモーダルが開きます。目的のスライドをクリックするとそのスライドへ移動します。

---

## 4. カバー（cover）

編集項目：
- **メインタイトル**
- **サブタイトル**（例：IT推進部）

プレビュー：メインカラー→アクセントカラーのグラデーション背景に白文字で大きく中央表示。

---

## 5. レイアウトパターン（12種類）と編集方法

編集パネル最上部の「レイアウト」をクリックすると、**12 種類のレイアウトパターン**がグリッド表示され、現在のスライドのデザインをワンクリックで変更できます。レイアウトを変更すると、既に入力済みのテキストは可能な範囲で引き継がれます（タイトル・画像・スピーカーノート・本文など）。

### ① カバー（cover）
「メインタイトル」「サブタイトル」を入力。表紙用のグラデーションデザイン。

### ② アジェンダ（agenda）
- **スライドタイトル**（例：本日のアジェンダ）
- **アジェンダ項目**（複数）：各行に「時間/ラベル」と「内容」を入力。「項目を追加」で行を追加、「✕」で削除。

### ③ セクション（section）
- **セクション番号 / ラベル**（例：SECTION 02）
- **セクションタイトル**（例：市場分析と機会）

メインカラー背景＋アクセントの下線バー付きの見出しスライド。

### ④ 中央テキスト（centered）
- **スライドタイトル**
- **強調テキスト（大）**（本文、例：変革は、今ここから。）
- **補足テキスト**

中央揃えの大きなメッセージスライド。

### ⑤ ナンバリング（numbered-list）
- **スライドタイトル**
- **ステップ項目**（複数）：大きな番号（01, 02...）付きで縦に並ぶ目次・手順リスト。

### ⑥ 2カラム（two-column）
- **スライドタイトル**（例：強みと課題）
- **左カラム見出し**＋左の項目リスト（複数）
- **右カラム見出し**＋右の項目リスト（複数）

各カラムにアクセント色の上部ラインが付いた 2 分割レイアウト。

### ⑦ 比較（comparison）
- **スライドタイトル**（例：A案 vs B案）
- **左ラベル（A案）** と左の特徴リスト（複数、緑系）
- **右ラベル（B案）** と右の特徴リスト（複数、赤系）

左右で対比する比較レイアウト。

### ⑧ 表（table）
- **スライドタイトル**
- **見出し行**（複数：見出しセルを1つずつ）
- **データ行**（複数）：行ごとに各列のセルを入力。「行を追加」で行を追加、「✕」で削除。

### ⑨ 統計（stats）
- **スライドタイトル**
- **数値カード**（複数）：各カードに「数値」（例：120%）と「ラベル」を入力。2×2 のグリッドに並びます。

### ⑩ プロセス（process）
- **スライドタイトル**
- **ステップ**（複数）：各ステップに「ラベル」と「説明」を入力。番号付きの円が矢印（→）でつながったフローレイアウト。※2 ステップ以上必須。

### ⑪ 棒グラフ（bar）
- **スライドタイトル**
- **グラフデータ**（複数）：各行に「ラベル」と「値（数値）」を入力して棒グラフを生成。
- **キーインサイト**（複数）：グラフ右側にドット付きで表示する読み解きコメント。

プレビュー上では SVG で描画された縦棒グラフが表示されます。

### ⑫ クロージング（closing）
- **スライドタイトル**
- **キーメッセージ**（本文）
- **サブタイトル**
- **項目**（複数）：末尾に並ぶ連絡先などの項目。

## 6. 画像の設定

全レイアウト共通で、各スライドに複数の画像を追加できます。

- **「画像を追加（5MB以下）」** ボタンで端末から画像を選択（PNG / JPEG など、5MB 制限あり。超えると警告）。
- 追加された画像は一覧に表示され、クリックすると選択されます（選択中は枠がハイライト）。
- 各画像の **X / Y（位置）** と **幅 / 高さ**（最小 30px）を数値で直接入力できます。
- プレビュー画面では：
  - **ドラッグ**で画像を移動（角をドラッグするとリサイズ、画像右上の ✕ で削除）。
  - 選択中は 4 隅に**リサイズハンドル**（nw / ne / sw / se）が表示され、これらをドラッグして大きさを変更できます。
- 画像は保存・各エクスポート（PPTX / HTML）にもそのまま反映されます。

## 7. スピーカーノート（発表者用メモ）

編集パネル最下部の「スピーカーノート」テキスト欄に、そのスライドの発表時に話す内容を入力できます（AI で作成した場合もここに反映されます）。※ソートや PPTX 出力には直接反映されず、主にメモとして利用します。

---

## 8. AIでつくる

「AIでつくる」ボタンでモーダルが開き、外部の生成 AI（ChatGPT / Gemini / Claude 等）を使ってスライド構成を作成できます。

### 使い方（3 ステップ）
1. **「AI用プロンプトをクリップボードにコピー」** ボタンで所定のプロンプトをコピー。
2. そのプロンプトを生成 AI に貼り付け、**議事録やメモを添付して送信**。AI はまずヒアリングを行い、次に Markdown 表形式で構成案を提示します。「はい」などと承認すると JSON を返します。
3. 返ってきた **JSON を入力欄に貼り付け、「▶ 貼り付けて反映」** を押すと、デッキが一括生成されます。

### AI モーダル内の補助機能
- **🎨 整形**ボタン：貼り付けた JSON を読みやすく整形（フォーマット）します。JSON が不正な場合はエラーを表示。
- **「プロンプト全文確認」**（折りたたみ）：AI へ渡すプロンプト全文をそのまま確認できます。

### AI が受け付けるデータ形式
- 全体構造：`{ "palette": 配色インデックス(0〜2), "font": フォント名, "slides": [...] }`
- 各スライド：`{ "type": レイアウト種別, "data": {...}, "note": スピーカーノート }`
- レイアウト種別は上記 12 種（cover / agenda / section / centered / numbered-list / two-column / comparison / table / stats / process / bar / closing）に対応し、各 `data` スキーマは上記の編集項目と対応します。
- 不正なレイアウト名は自動的に cover へフォールバックされます。

## 9. 設定

設定モーダルでは以下を変更できます。

- **言語**：日本語 / English を切り替え（選択はブラウザに記憶）。
- **UIカラーテーマ**：アプリ全体の配色を「ダーク（標準）」「スモーキー」から選択。
- **フッター設定**：
  - 「フッターを表示する」チェックボックスと、**左 / 中央 / 右** の3箇所のテキストを設定。
  - `{page}` / `{total}` はそれぞれ「現在のページ番号 / 総ページ数」に自動置換されます（例：`{page} / {total}` → `3 / 12`）。
- **デフォルトレイアウト**：新規デッキ作成時に使用する初期レイアウトを選択。
- **Undo/Redo 履歴数**：元に戻す/やり直しの最大履歴数（10〜30）。
- **エディタ配置**：編集パネルとプレビューの「左右」⇔「上下」。

---

## 10. 出力（エクスポート）

「出力」ボタンのドロップダウンから選択します。

### PowerPoint（.pptx）
- **PptxGenJS** を使用して 16:9（ワイド）の .pptx ファイルを生成・ダウンロード。
- 全スライドがレイアウトに応じて変換され（棒グラフはネイティブな BAR チャート、表は PPT テーブルとして出力）、画像・フッター（右下に透かし **"Created with Slibo"** 付き）も反映されます。
- ファイル名は先頭スライドのタイトルから生成されます。

### HTML
- 単体で動作する**自己完結型**の HTML ファイル（1280×720 のスライド群）を生成・ダウンロード。
- 下部に前へ/次へナビゲーションバー、ページインジケータ、全画面ボタンが付いた**プレゼンテーションビューア**として動作します。
- 画像、フッター、配色、フォントもすべて埋め込まれます。

## 11. 保存・読み込み

- **オートセーブ**：編集内容は変更のたびにブラウザの **localStorage**（キー `slibo-autosave`）へ自動保存されます。ページを再読み込みしても、最後の状態が自動復元されます。
- **設定の保存**：言語・UIテーマ・デフォルトレイアウト・Undo/Redo 履歴数・エディタ配置はキー `slibo-settings` に保存されます。
- ブラウザを消去（シークレットモードや別ブラウザ、ローカルストレージのクリア）すると編集内容は戻りませんので、必要に応じて「出力」でファイルとして書き出しておくことを推奨します。

---

## 12. キーボードショートカット

入力欄（INPUT / TEXTAREA / 編集可能要素）にフォーカスがあるときは、スライド操作用のショートカットは無効です。

| ショートカット | 動作 |
|----------------|------|
| Ctrl / Cmd + Z | 元に戻す（Undo） |
| Ctrl / Cmd + Shift + Z、または Ctrl / Cmd + Y | やり直し（Redo） |
| Ctrl / Cmd + D | 現在のスライドを複製 |
| Ctrl / Cmd + M | 新しいスライドを追加 |
| Alt + ↑ / ↓ | 現在のスライドを上 / 下へ移動 |
| ↑ / ↓ | 前 / 次のスライドへ移動 |
| Delete / Backspace | 現在のスライドを削除（最後の1枚は不可） |
| ? | 使い方ガイド / ウェルカム画面を表示 |
| Esc | モーダルやメニューを閉じる、レイアウトパネルを畳む |

---

## 13. プレビューでのページ移動

- プレビュー画面の左右に表示される矢印ボタンで前 / 次のスライドへ移動（ホバー時のみ表示）。
- **マウスホイール**（縦・横どちらも）でスライドを送り/戻すことができます。
- モバイルでは**スライド上の左右スワイプ**でページ移動（編集欄を除く）。

---

## 14. モバイル対応

画面幅 768px 未満ではモバイル向け UI に切り替わります。

- 左端の**エッジハンドル**をタップ、または画面左端から右へスワイプすると**スライド一覧（サイドバー）**が現れます。
- 上部の**ハンバーガーメニュー**から、フォント選択・カラーテーマ・Undo/Redo・サンプル/新規デッキ・使い方ガイド・設定などにアクセスできます（元に戻す/やり直し、JSON保存/読込、サンプル/新規デッキ、フォント、カラーテーマ、AIでつくる、設定、出力 PPTX/HTML）。
- ダウンロードアイコンから PPTX / HTML 出力が可能。
- 編集パネルとプレビューは縦に積み重なり、プレビューは高さ上限付きのコンパクト表示になります。
